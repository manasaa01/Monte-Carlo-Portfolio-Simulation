# Project Title

## Overview

This project demonstrates a Monte Carlo simulation for portfolio analysis. It allows users to simulate future portfolio values based on historical asset returns and predefined portfolio weights.

## How to Use

1.  **Define Portfolio and Simulation Parameters**: Modify the `assets`, `weights`, `initial_portfolio_value`, `num_simulations`, and `num_trading_days` in the first code cell.
2.  **Run the Simulation**: Execute the cells sequentially to run the Monte Carlo simulation.
3.  **Analyze Results**: Review the generated plots and statistical summaries of the simulated portfolio paths and final values, including VaR and CVaR.
4.  **Compare Scenarios**: The notebook includes a section to compare simulation results with different asset return characteristics.

## Dependencies

The following Python libraries are required:
- `numpy`
- `pandas`
- `matplotlib`
- `seaborn`

These can be installed using pip:

```bash
pip install numpy pandas matplotlib seaborn
```
